# Code of Conduct

This project adopts the **[Contributor Covenant, version 2.1][cc]** as its
code of conduct.

The full text is available at the link above. Contributors, maintainers,
and anyone interacting with this project — in issues, pull requests, code
reviews, discussions, or any other project space — are expected to
follow it.

## Reporting

Concerns about behaviour in any project space can be reported privately to:

- **nicolaskaitinnis1991@gmail.com**

All reports will be reviewed and investigated promptly and fairly. The
maintainer respects the privacy and safety of the reporter.

## Enforcement

The maintainer of this project follows the enforcement guidelines outlined
in the Contributor Covenant 2.1 ([Enforcement Ladder][ladder]) when
determining the consequences for any action deemed in violation.

[cc]: https://www.contributor-covenant.org/version/2/1/code_of_conduct/
[ladder]: https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement
