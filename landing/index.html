What's MCP?

The Model Context Protocol is Anthropic's open standard for letting AI agents call structured tools. An MCP server exposes tools (with schemas + handlers); any MCP client (Claude Desktop, Claude Code, Cursor, Cline, custom apps) can use them.

This server is the host-side bridge between agents and Airbnb. It treats the host as the user — not the guest, not Airbnb itself.

Quick install

Three steps. No accounts. Public data tools work out of the box.

  1. 1

    Clone & build

    git clone https://github.com/nicolaskaitinnis1991/mithgard-bnb-mcp
cd mithgard-bnb-mcp
npm ci && npm run build
  2. 2

    Wire it into Claude Desktop

    Add to ~/Library/Application Support/Claude/claude_desktop_config.json (macOS) or the equivalent on your platform: 

    {
  "mcpServers": {
    "bnb": {
      "command": "node",
      "args": ["/absolute/path/to/mithgard-bnb-mcp/dist/index.js"]
    }
  }
}
  3. 3

    Restart Claude Desktop and ask a question

    Try: "Search Airbnb listings in Berlin for 2 adults next weekend." Claude will pick the airbnb_search tool and return real results.

Nine tools

Two run live against public Airbnb data today. Seven are demo-grade with realistic fixtures, ready to flip on the day Airbnb's Partner API access lands.

  • airbnb_search live

    Search public Airbnb listings. Returns ids, titles, prices, locations, ratings.

  • airbnb_listing_details live

    Full listing detail: amenities, capacity, host card, reviews summary.

  • host_insights demo

    Occupancy, revenue, competitor delta, pricing recommendations per listing.

  • guest_message_assistant demo

    Drafts 3 host-voiced replies to a guest message. Always approval_required.

  • booking_request_triage demo

    Risk-scores a booking 0–100 with auditable reasons. Auto-accept / review / decline.

  • smart_pricing demo

    Daily price suggestions with weekday/seasonal/event factors. 30-day horizon.

  • calendar_optimizer demo

    Detects calendar gaps. Recommends discount / min-stay-relax / block actions.

  • review_responder demo

    Drafts a host-voiced reply, classifies sentiment, flags escalation cases.

  • turnover_coordinator demo

    Cleaning brief, 8-item checklist, crew message, estimated duration per turnover.

What this is not

  • Not an official Airbnb product. Not affiliated with Airbnb.
  • Not a scraper-as-a-service. The two live tools read the same public pages a browser does, with caching and rate limiting.
  • Not a guest-side travel agent. It's the opposite — host-side ops.
  • Not a black box. Every recommendation is structured, auditable, and re-runnable.

Why this exists

I host on Airbnb (Superhost). I also build software. Every tool that could save me hours per week — pricing assistant, gap optimizer, guest-message drafter — either doesn't exist, lives behind a $79/mo SaaS, or gives me no audit trail.

MCP makes this fixable for the first time. One small open-source server, one host's calendar, one agent that reasons about both.

The seven demo tools are the bet: when an Airbnb Partner API key lands, they flip from fixture-backed to live in one afternoon. The interface is already designed.
