# Getting Support

Thanks for using `mithgard-bnb-mcp`!

## I have a question

- **Bug or unexpected behaviour?** → Open a [bug issue](.github/ISSUE_TEMPLATE/bug.yml).
- **Feature request?** → Open a [feature issue](.github/ISSUE_TEMPLATE/feature.yml).
- **How do I use this?** → Read the [README](./README.md) and [docs/](./docs/) first. If still stuck, open a GitHub Discussion.
- **Security issue?** → See [SECURITY.md](./SECURITY.md) — please don't post publicly.
